## 🚀 Sobre a GENNEOS

**GENNEOS — "Pedido é uma ordem."**
Somos uma empresa de **ordem de serviço (OS)** com foco inicial em **lavanderias industriais**, projetada para expandir para outros setores no futuro. Nosso objetivo é resolver a dor de **formalizar, padronizar e facilitar** a operação entre empresa e cliente, oferecendo um sistema de OS **altamente personalizável**, simples de adotar e fácil de escalar.

Nosso tom é profissional, mas com leve humor de startup — porque gestão séria não precisa ser sisuda. 💙

---

## 💡 O que fazemos

* Sistema de Ordem de Serviço (OS) configurável para lavanderias industriais.
* Fluxos para criação → aceite → execução → faturamento de OS.
* Painel web para operadores e aplicativo móvel para motoristas/coletas.
* Customização de formulários, regras de negócio e relatórios para cada cliente.
* Integrações com ERPs e gateways de pagamento (plug-and-play).

## 🧰 Tecnologias que usamos (atual e lovável)

* ⭐ **Kotlin** — backend e Android (linguagem preferencial para novos módulos)
* 🌐 **React / TypeScript** — painel web e webapp
* ☁️ **Arquitetura Cloud-native** — contêineres, CI/CD e deploy automatizado
* 🔒 **OAuth2 / JWT** — autenticação e autorização
* 📦 **API REST + gRPC** — integrações com ERPs e serviços internos
* 🧪 **Testes automatizados** — unit, integration e e2e
* 📊 **Observability** — métricas, logs estruturados e alertas
* ♻️ **Infra IaC** — Terraform / Ansible (quando aplicável)

> Observação: somos pragmáticos — se uma tecnologia resolve o problema melhor, avaliamos e adotamos. Prioridade: entrega com qualidade.

## 🤝 Como contribuir

1. Fork o repositório
2. Crie uma branch: `git checkout -b minha-feature`
3. Faça seu commit: `git commit -m 'feat: nova funcionalidade'`
4. Push para sua branch: `git push origin minha-feature`
5. Crie um Pull Request 🚀

**Boas práticas:** commits pequenos e autocontidos, documente mudanças de schema, inclua testes e descreva o propósito do PR. Mantenha `main` protegido e use convenções como `feat/`, `fix/`, `chore/`.
